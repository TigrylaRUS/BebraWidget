Приложение создано для подбора мемов к вашей фотографии в галерее. При запуске у вас будет выбор из имеющихся альбомов. Выбрав альбом, фотографии отправляется на сервер, где он в свою очередь подбирает наиболее похожую картинку. Т.е. вам по итогу будет предоставлен виджет, который будет показывать ваше фото и соответствующее ему мемное изображение, также фото из альбома будет периодически меняться.

На данный момент:
Сначала я использовал общедоступный API сервера, который предоставлял мемы, он работает с переменным успехом ибо подбирает картинки на основе схожего хэша картинок. Поэтому планируется написание собственного сервера для реализуемой задачи.# BebraWidget
